# Checklist de validação

Preencha após testar. Itens desmarcados não representam testes já executados.

- [ ] Abrir index.html e conferir título, textos e layout.
- [ ] Testar navegação para A ideia, Como funciona e Experimentar.
- [ ] Adicionar uma tarefa e conferir A fazer e o contador.
- [ ] Rejeitar uma tarefa composta somente por espaços.
- [ ] Mover tarefa para Em andamento e depois Concluído.
- [ ] Conferir que o contador de concluídas acompanha a mudança.
- [ ] Recarregar a página e verificar que o quadro permanece salvo.
- [ ] Cancelar uma exclusão e confirmar que a tarefa continua.
- [ ] Confirmar a exclusão e conferir remoção e contador.
- [ ] Testar texto longo e acentos.
- [ ] Testar teclado: Tab, Enter, campos, select e FAQ.
- [ ] Conferir em tela de celular e computador, sem conteúdo cortado.
- [ ] Abrir o console do navegador e conferir ausência de erros.
- [ ] Abrir a URL pública do GitHub Pages e repetir os testes principais.
